# জয় বাংলা — গ্লোবাল বাংলা প্ল্যাটফর্ম (Global Bangla Platform)
> **বাংলা ভাষা, সাহিত্য, সংস্কৃতি ও বিজ্ঞানের বিশ্বজয়ের জন্য একটি আধুনিক রিয়্যাক্ট ও নোডজেএস ফুলস্ট্যাক প্ল্যাটফর্ম**

---

## 🌟 ওভারভিউ (Overview)

**গ্লোবাল বাংলা প্ল্যাটফর্ম** হলো একটি সম্পূর্ণ আধুনিক ফুলস্ট্যাক ওয়েব অ্যাপ্লিকেশন, যা আধুনিক ফ্রন্টএন্ড ফ্রেমওয়ার্ক **React (Vite)** এবং ব্যাকএন্ড **Node.js (Express + SQLite)** দিয়ে নির্মিত। এটি বিশ্বজুড়ে ত্রিশ কোটি বাঙালির মাতৃভাষাকে একবিংশ শতাব্দীর এআই, বিজ্ঞান ও উন্মুক্ত জ্ঞানের শীর্ষে পৌঁছে দেওয়ার সমন্বিত ডিজিটাল প্ল্যাটফর্ম।

> **উৎসর্গ:** "পৃথিবীর সমস্ত বাঙালির জন্য তৈরি, ❤️ দিয়ে"

---

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

- **ফ্রন্টএন্ড ফ্রেমওয়ার্ক:** React 19, Vite (সুপারফাস্ট HMR ও মডুলার কম্পোনেন্ট আর্কিটেকচার)
- **ডিজাইন সিস্টেম:** গ্লাস-মরফিক ডার্ক মোড ভ্যানিলা সিএসএস (Vanilla CSS Tokens, Micro-animations)
- **গ্রাফিক্স ও অডিও:** HTML5 Canvas 2D Physics Engine, Web Audio API Waveform Visualizer
- **ব্যাকএন্ড:** Node.js, Express 5 REST API
- **ডেটাবেস:** `node:sqlite` (Node.js 24-এর নেটিভ `DatabaseSync` — কোনো এক্সটারনাল ডাটাবেস ছাড়া লোকাল পারসিস্টেন্স)
- **লোগো:** নিরপেক্ষ বৈশ্বিক বাংলা সাংস্কৃতিক প্রতীক (স্টাইলাইজড 'অ' ও মুক্ত জ্ঞান ভাস্কর্য, কোনো নির্দিষ্ট জাতীয় পতাকা ছাড়া)

## 🚀 মূল মডিউল ও ইন্টারঅ্যাক্টিভ কম্পোনেন্টস

1. **ব্র্যান্ড ও নেভিগেশন (`Navbar.jsx` & `Logo.jsx`):**
   - নিরপেক্ষ বাংলা সাংস্কৃতিক গোল্ডেন-এমেরাল্ড প্রতীক এবং রেসপনসিভ নেভিগেশন।
2. **হিরো সেকশন (`Hero.jsx` & `FloatingBg.jsx`):**
   - ব্যাকগ্রাউন্ডে ভাসমান বাংলা বর্ণমালার অ্যানিমেশন এবং সমন্বিত রোডম্যাপ।
3. **লাইভ স্ট্যাটিস্টিকস রিবন (`StatsRibbon.jsx`):**
   - ব্যাকএন্ড এপিআই (`/api/stats`) থেকে লাইভ ডেটা কাউন্টার।
4. **চারটি কৌশলগত ভিত্তি (`PillarsSection.jsx`):**
   - ভাষা প্রযুক্তি ও এআই, সাহিত্য ও অনুবাদ বিপ্লব, সংস্কৃতি ও পপ-কালচার, এবং বিজ্ঞান ও উন্মুক্ত শিক্ষা।
5. **উদ্ভাবনী ডিজিটাল ল্যাব হাব (`InteractiveHub.jsx`):**
   - **এআই টোকেনায়ন ল্যাব (`TokenizerLab.jsx`):** সাবওয়ার্ড BPE বনাম ক্যারেক্টার স্প্লিটিং তুলনা ও টোকেন সাশ্রয় বিশ্লেষণ।
   - **ভার্চুয়াল সায়েন্স ল্যাব (`ScienceLab.jsx`):** ক্যানভাস ভিত্তিক সরল দোলক ও আলোর প্রতিসরণ (স্নেলের সূত্র) সিমুলেটর।
   - **বাংলা কমন ভয়েস রেকর্ডার (`VoiceRecorder.jsx`):** Web Audio API দিয়ে লাইভ ভয়েস রেকর্ড ও উপভাষাভিত্তিক অনুদান।
   - **উন্মুক্ত বাংলা অভিধান (`DictionarySearch.jsx`):** বাংলা অর্থ ও পদবিন্যাস অনুসন্ধান।
   - **প্রযুক্তি পরিভাষাকোষ (`TechGlossary.jsx`):** এআই ও কম্পিউটিং পরিভাষা এবং কমিউনিটি ভোটিং।
6. **ডিজিটাল ক্লাসিক সাহিত্যাগার (`LiteratureSection.jsx` & `LiteratureModal.jsx`):**
   - রবীন্দ্র-নজরুল-মধুসূদন-জীবনানন্দের ক্লাসিক রচনা পাঠ এবং ফন্ট সাইজ নিয়ন্ত্রণ (A- / A+)।
7. **গ্লোবাল বাংলা অঙ্গীকার প্রাচীর (`PledgeWall.jsx`):**
   - লাইভ ফর্ম ও গ্লোবাল অঙ্গীকার সংগ্রহশালা।
8. **উদ্ভাবনী আইডিয়া বোর্ড (`IdeaBoard.jsx`):**
   - কমিউনিটি প্রস্তাবনা ও আপভোটিং সিস্টেম।
9. **ফুটার (`Footer.jsx`):**
   - *"পৃথিবীর সমস্ত বাঙালির জন্য তৈরি, ❤️ দিয়ে"* উৎসর্গবাণী।

## 🏃‍♂️ কীভাবে চালাবেন (How to Run)

### এক ক্লিকে সম্পূর্ণ প্ল্যাটফর্ম চালু করা (React + Node.js):
```powershell
cd c:\Users\joysr\Documents\joy_bangla\projects\global-bangla-fullstack
npm run dev
```

ব্রাউজারে গিয়ে ওপেন করুন:
👉 **[http://localhost:3000](http://localhost:3000)**

*(ব্যাকএন্ড এপিআই স্বয়ংক্রিয়ভাবে `http://localhost:5000`-এ রান করবে এবং Vite স্বয়ংক্রিয়ভাবে সব `/api/*` রিকোয়েস্ট প্রক্সি করবে।)*

## 📡 REST API এন্ডপয়েন্টসমূহ (API Endpoints)

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/stats` | মোট অঙ্গীকার, আইডিয়া, পরিভাষা ও অডিও পরিসংখ্যান |
| `GET` | `/api/pledges` | সমস্ত অঙ্গীকারের তালিকা |
| `POST`| `/api/pledges` | নতুন অঙ্গীকার যুক্ত করা |
| `GET` | `/api/ideas` | সমস্ত আইডিয়া ও প্রস্তাবনা |
| `POST`| `/api/ideas` | নতুন আইডিয়া সাবমিট করা |
| `POST`| `/api/ideas/:id/vote`| আইডিয়াতে ভোট দেওয়া |
| `GET` | `/api/glossary` | প্রযুক্তি পরিভাষা অনুসন্ধান ও ক্যাটাগরি ফিল্টার |
| `POST`| `/api/glossary/:id/vote` | পরিভাষায় সমর্থন ভোট দেওয়া |
| `GET` | `/api/dictionary` | বাংলা অভিধান অনুসন্ধান (বাংলা ও ইংরেজি) |
| `GET` | `/api/literature` | ধ্রুপদী সাহিত্যের তালিকা |
| `GET` | `/api/literature/:id` | সাহিত্যের পূর্ণাঙ্গ পাঠ্য |
| `GET` | `/api/voice/samples` | জমা হওয়া অডিও নমুনার তালিকা |
| `POST`| `/api/voice/submit` | নতুন ভয়েস স্যাম্পল জমা দেওয়া |
| `POST`| `/api/tokenizer` | টেক্সট টোকেন বিশ্লেষণ ও সাশ্রয় হিসাব |
