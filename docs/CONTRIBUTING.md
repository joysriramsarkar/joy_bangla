# 🤝 গ্লোবাল বাংলা কন্ট্রিবিউটর গাইডলাইন (Contributing Guidelines)

গ্লোবাল বাংলা (Global Bangla) একটি উন্মুক্ত, গণমুখী ও বৈশ্বিক উদ্যোগ। আপনি একজন সফটওয়্যার ইঞ্জিনিয়ার, ভাষাবিদ, শিক্ষক, শিক্ষার্থী, অনুবাদক কিংবা সাধারণ একজন বাংলাভাষী—আপনার যেকোনো অবদান এই মহতী উদ্যোগের জন্য অত্যন্ত মূল্যবান!

---

## 🧭 অবদানের ক্ষেত্রসমূহ (Contribution Tracks)

### ১. 👨‍💻 সফটওয়্যার ডেভেলপার (Software Developers)
- **ফ্রন্টএন্ড:** React, Next.js, Tailwind CSS, অথবা লাইটওয়েট ভ্যানিলা এইচটিএমএল/সিএসএস/জেএস দিয়ে ইউজার ইন্টারফেস সমৃদ্ধ করুন।
- **ব্যাকএন্ড ও এপিআই:** ডিকশনারি ও গ্লসারি এপিআই তৈরি, পারফরম্যান্স অপটিমাইজেশন, ক্যাশিং ও অফলাইন ডাটাবেস।
- **এআই ও এনএলপি:** টেক্সট প্রিপ্রসেসিং, বাংলা ইউনিকোড নরমালাইজেশন, স্পিচ রিকগনিশন মডেল ট্রেনিং ও হাগিংফেস ডেটাসেট তৈরি।
- **টুলস ও এক্সটেনশন:** ব্রাউজার এক্সটেনশন, কীবোর্ড লেআউট প্লাগইন, ভিএস কোড এক্সটেনশন ইত্যাদি।

### ২. 📚 ভাষাবিদ ও ব্যাকরণবিদ (Linguists & Editors)
- উন্মুক্ত অভিধানের শব্দের অর্থ, উচ্চারণ (IPA), পদ ও ব্যুৎপত্তি যাচাই ও সংশোধন।
- নতুন প্রযুক্তির জন্য সহজবোধ্য ও স্বাভাবিক বাংলা পারিভাষিক শব্দ প্রস্তাব ও পর্যালোচনা।
- আঞ্চলিক উপভাষার সঠিক বানানরীতি ও অর্থ সংরক্ষণ।

### ৩. ✍️ অনুবাদক ও প্রযুক্তি লেখক (Translators & Content Creators)
- উইকিপিডিয়া এবং বাংলা নলেজ হাবের জন্য কম্পিউটার সায়েন্স, পদার্থবিজ্ঞান, জীববিজ্ঞান, চিকিৎসা ও অর্থনীতির উচ্চমানের প্রবন্ধ রচনা।
- ওপেন সোর্স ডকুমেন্টেশন (যেমন MDN Web Docs, Linux Manuals, Python/JavaScript Docs) বাংলায় রূপান্তর।

### ৪. 🎙️ কণ্ঠদাতা (Voice Contributors)
- বাংলা কমন ভয়েস প্ল্যাটফর্মে আপনার কণ্ঠে প্রমিত বা স্থানীয় উপভাষায় বাক্য পাঠ করে অডিও রেকর্ড করা।
- অন্যান্য সদস্যদের অডিও শুনে উচ্চারণ শুদ্ধতা যাচাই করা।

## 🔤 বাংলা ইউনিকোড ও টেক্সট স্ট্যান্ডার্ড (Bangla Unicode Guidelines)

বাংলা এনএলপি ও সফটওয়্যার ডেভেলপমেন্টে ইউনিকোড সংক্রান্ত সমস্যা এড়াতে নিম্নলিখিত বিষয়গুলো মেনে চলুন:

1. **ইউনিকোড নরমালাইজেশন:** সর্বদা `NFC` (Normalization Form C) ব্যবহার করুন।
2. **যুক্তবর্ণ ও কার-চিহ্ন:** 
   - এ-কার (`ে`) ও ও-কার (`ো`) ইনপুটের সঠিক ক্রম বজায় রাখুন।
   - য-ফলা (`্য`), র-ফলা (`্র`), রেফ (`র্`) ও হসন্ত (`্`)-এর সুনির্দিষ্ট ইউনিকোড কোডপয়েন্ট নিশ্চিত করুন।
   - ক্ষ, জ্ঞ, ষ্ণ, ঞ্চ ইত্যাদির অভ্যন্তরীণ ইউনিকোড সিকোয়েন্স প্রমিত রাখুন।
3. **দাঁড়ি ও যতিচিহ্ন:** বাংলা পূর্ণচ্ছেদ হিসেবে সর্বদা বাংলা দাঁড়ি (`।` - U+0964) ব্যবহার করুন, কোনোভাবেই দেবনাগরী দাঁড়ি বা পাইপ (`|`) ব্যবহার করবেন না।

## 🚀 গিটহাব ওয়ার্কফ্লো ও পিআর গাইডলাইন (GitHub Workflow)

1. **ফর্ক ও ক্লোন:** রিপোজিটরিটি আপনার গিটহাব অ্যাকাউন্টে Fork করুন এবং লোকাল মেশিনে ক্লোন করুন:
   ```bash
   git clone https://github.com/<your-username>/global-bangla.git
   ```

2. **নতুন ব্রাঞ্চ তৈরি করুন:** আপনার কাজের জন্য অর্থপূর্ণ একটি ব্রাঞ্চ নাম দিন:
   ```bash
   git checkout -b feature/tech-glossary-ai
   # অথবা
   git checkout -b fix/dictionary-spelling-correction
   ```

3. **কমিট মেসেজ কনভেনশন:**
   আমরা কনভেনশনাল কমিট মেসেজ অনুসরণ করি:
   - `feat: add 50 new AI terms to glossary`
   - `fix: resolve unicode normalization bug in dict parser`
   - `docs: update roadmap for 2027 milestone`
   - `data: add 200 sylheti dialect pronunciation entries`

4. **পুল রিকোয়েস্ট (Pull Request) জমা দিন:**
   - আপনার ব্রাঞ্চ থেকে মেইন ব্রাঞ্চে PR ওপেন করুন।
   - PR ডেসক্রিপশনে আপনার কাজের সংক্ষিপ্ত বিবরণ এবং প্রাসঙ্গিক ইস্যু নম্বর (#123) উল্লেখ করুন।
